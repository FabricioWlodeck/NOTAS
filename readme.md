# NOTAS - [[UNaM Facultad de Ingeniería]]

Bienvenido a mi repositorio de notas académicas de la facultad.

## Estructura de Carpetas

- `01_Facultad/`: Apuntes, guías y material de estudio.

## Convenciones de Uso

### Etiquetas (Tags)
- `#pendiente`: Tareas o temas a procesar.
- `#FinalPendiente`: Final siguiente a rendir, en preparación.
- `#importante`: Contenido de alta prioridad.
- `#apunte`: Notas de clase estructuradas.

### Enlaces
- Usamos `[[Nombre de nota]]` para enlaces internos.
- Usamos `[[Nota#Encabezado|Descripción]]` para vincular secciones específicas.

### Imágenes
- Todas las imágenes se guardan en la carpeta `/Attachments`.

## Configuración y Sincronización
- **Cross-Platform:** Repositorio optimizado para Windows y Linux.
- **Saltos de línea:** `.gitattributes` con `* text=auto`.
