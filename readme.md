# NOTAS - Base de conocimiento

Bienvenido a mi repositorio personal de notas. Esta bóveda de Obsidian está estructurada para centralizar el conocimiento académico, el control de gastos y pensamientos varios.

## Estructura de Carpetas

- `01_Facultad/`: Apuntes, guías y material de estudio.
- `02_Gastos/`: Registro de finanzas personales.
- `03_Pensamientos/`: Notas sueltas, ideas y borradores.
- `Attachments/`: Repositorio central de imágenes y archivos adjuntos.

## Convenciones de Uso

### Etiquetas (Tags)
Para mantener el orden, utilizamos etiquetas para identificar el estado o tipo de contenido:
- `#pendiente`: Tareas o temas a procesar.
- `#FinalPendiente`: Final siguiente a rendir, en preparación.
- `#importante`: Contenido de alta prioridad.
- `#idea`: Notas rápidas o reflexiones.
- `#apunte`: Notas de clase estructuradas.

### Enlaces
- Usamos `[[Nombre de nota]]` para crear enlaces internos entre documentos.
- Usamos `[[Nota#Encabezado|Descripción]]` para vincular secciones específicas dentro de una nota.

### Imágenes
- Todas las imágenes deben guardarse en la carpeta `/Attachments`.
- Las rutas de los archivos son relativas para asegurar que se visualicen correctamente tanto en Obsidian como en GitHub.

## Configuración y Sincronización
- **Cross-Platform:** Este repositorio está optimizado para funcionar en Windows y Linux.
- **Saltos de línea:** Se utiliza `.gitattributes` con `* text=auto` para garantizar que los saltos de línea se gestionen correctamente sin importar el sistema operativo, evitando "cambios fantasma" en Git.
